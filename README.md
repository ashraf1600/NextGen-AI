# 🚀 NextGen AI

**NextGen AI** is a modern documentation platform focused on **Artificial Intelligence** and **Generative AI**. It provides structured learning paths, practical guides, and hands-on resources to help developers, students, and AI enthusiasts master modern AI technologies.

## ✨ Features

- 🤖 AI & Generative AI Documentation
- 📚 Structured Learning Roadmaps
- 🧠 Large Language Models (LLMs)
- 🔗 LangChain & AI Orchestration
- 🔍 Retrieval-Augmented Generation (RAG)
- 🤖 AI Agents
- 💻 Practical Examples & Projects
- 📱 Responsive Design
- 🌙 Dark Mode Support

## 🛠️ Built With

- **VitePress**
- **Node.js**
- **Markdown**
- **GitHub Pages**

## 🚀 Getting Started

```bash
git clone https://github.com/YOUR_USERNAME/nextgen-ai.git

cd nextgen-ai

npm install

npm run docs:dev
```

Build for production:

```bash
npm run docs:build
```

Preview locally:

```bash
npm run docs:preview
```
